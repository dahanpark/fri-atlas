# FRI ATLAS

한국 기본 세계 지도, 무료 공개지도, 지도 좌/비교 우, 에디토리얼+Frutiger Aero를 유지한다. 최신 사용자 지시가 이전 명세보다 우선한다. v2 방향과 데이터 경계는 [제품 기준](references/product.md)을 읽는다. 이 문서는 완료 증명이 아니다.

## 팀과 전달

소스·AGENTS.md·현재 배포 상태부터 확인한다. 팀 요청에는 조정·제품, 원천·연동 조사, 디자인·구현, 독립 검토를 실제 에이전트로 배분한다. 단순 수정은 필요한 역할만 쓴다. 조사자는 사실·출처·확인시각·권리·결측을, 구현자는 변경파일·실행증거·미구현을, 독립 검토자는 결함·재현·잔여 한계를 넘긴다. 생산자가 독립 검토를 대체하지 않는다.

## 지도와 분석

지도 정지 약300ms 뒤 전국 로컬 인덱스를 viewport로 필터링해 모든 해당 마커와 Navigator를 갱신한다. 지도 마커에 TOP10/20 상한을 적용하지 않는다. 공용 API를 지도 이동마다 호출하지 않는다. source 선택 UI는 제거한다. 이동 EXPLORER/정지 CATCH와 현재 화면 상태를 표시한다.

ANALYSIS 클릭 시 bounds·시각을 고정하고 오른쪽에 TOP10/20 후보(기본10)만 표시한다. 현재 화면 전체마커와 분석 snapshot 목록을 분리한다. 마커·카드 선택을 연결하고 오래된 응답은 취소/요청ID로 무효화한다. 빈 결과·미조회·오류·일부 자료를 구분한다. 세계 지도 이동 가능과 한국 밖 데이터 확보를 혼동하지 않는다.

Navigator는 원천 객체·화면 후보·분석 표시 수와 마지막 분석 bounds/시각을 구분한다. OSM 1,119개는 영업 골프장 총수나 공식 전국 명부가 아니다. 이름·대표점이 같다는 이유로 자동 병합하지 않고 type/id를 보존한다. 공식 명부 대조와 좌표·영업상태 검증의 완료 범위를 기록한다.

## 간결 비교와 근거

기본 카드에는 이름·썸네일·NAVER별점/후기수·주중/주말18홀 일반요금·캐디피·위치·서울/부산 도로거리/시간·장점/유의점·예약CTA를 짧게 둔다. 장점과 유의점은 각각 최대2개·각20자 내외다. 이전 최소25항목·긴 기본표 요구는 적용하지 않는다. 결측은 —, 근거·조건·상태는 한곳 펼치기에 모은다.

추천은 확인된 NAVER평점 우선, 가격은 주중/주말 조건을 구분한다. 서울/부산거리 정렬도 지원하되 결측은 뒤로 보낸다. 값이 없으면 가짜 평점·총액·순위를 만들지 않고 순위 미산정으로 표시한다. 종전 가중치30/30/25/15는 척도·근거가 확보된 경우의 배경 기준이며 최신 평점우선 정렬을 대체하지 않는다.

NAVER 지역검색API는 별점·방문리뷰를 반환하지 않는다. 2026년 별점 재개 사실과 API 미제공을 구분한다. 대체 후기 샘플을 NAVER후기·전국 총평으로 위장하지 않는다. 원문 복제·차단우회·내부 endpoint 재현을 하지 않는다. 편집요약도 제공처·표본·기간·대표성 한계를 보존하고 exportAllowed=false이면 HTML에 재배포하지 않는다.

주중/주말·회원조건·홀수·적용일·티타임·세금·팀/인당을 구분한다. 소수 공식 캐디피로 전국 추정값을 채우지 않는다. 날짜·인원·모든 필수비가 검증되지 않으면 총액은 산출 불가다. 정보충실도는 코스품질 점수가 아니다.

## 위치·사진·외부 연결

OSM way/relation 중심, 공식 지도점, 차량입구를 구분한다. 공식점 확인만으로 입구검증 완료라고 하지 않는다. 주소·명칭 변경·좌표 원천을 대조하고 위치감사를 보존한다. 주변 객체에 근거 없이 코스 이름을 붙이지 않는다.

도로 수치는 실제 경로 응답에서만 쓴다. 서울시청·부산시청 기준점을 명시한다. OSRM table은 분석 시 선택 후보에 대해서만 2×최대20 요청하며 교통미반영·대표점도착·조회시각을 표시한다. 경로 시험성공과 전체 앱 연결완료를 구분한다. 미연결·제주 경로를 직선거리나 추정 운전시간으로 채우지 않는다.

실제 코스에 매칭되고 권리확인된 사진만 쓴다. 의령 사진의 CC BY-SA4.0 저작자·출처·변경 여부를 표시한다. 타코스나 일반 골프사진으로 빈값을 채우지 않는다. onerror fallback과 실제 렌더검증이 필요하다.

공식 예약안내, XGOLF·티스캐너·카카오골프 서비스 열기, 검증된 코스별 직접예약을 구분한다. URL에 임의 코스 파라미터를 붙이지 않는다. 링크는 예약·결제API 연동이 아니다. 신규 유료API·제휴메일·계약은 공개 구현지시의 자동 승인이 아니다.

## 저장·검증·공개

HTML·공유·mailto·최대4곳 비교·관심 snapshot 복원을 보존한다. HTML에는 날짜·인원·코스·bounds·시각·요금조건·출처·결측을 남기되 원천별 재배포허용 범위를 따른다. mailto는 초안이며 발송·첨부완료로 보고하지 않는다. 외부 문자열 escape·안전URL·stale request 방어를 유지한다.

실브라우저에서 정지 자동갱신, 전체마커와 TOP목록, 좌표·마커/카드 연결, 결측정렬, 사진, 경로·요금조건, export·관심·지역간 비교를 확인한다. 데스크톱/390px, 키보드·대비·모션감소를 본다. 독립 분할검토→보강→새 전체검토를 거치며 자기점수로 대체하지 않는다.

공개저장소에 비밀·개인정보·재배포불가 원문을 넣지 않는다. 소스 push→Actions→Pages, 공개URL·핵심asset SHA일치·실기능을 확인한다. v2 제작 중 v1 배포성공을 v2완료로 보고하지 않는다. 구현/자료확보/미구현/실제 공개검증을 나눠 보고한다.
