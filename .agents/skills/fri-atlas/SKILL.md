# FRI ATLAS

세계 지도에서 고정한 영역의 골프장을 발견하고 확인 가능한 정보로 비교하는 공개 웹 프로그램을 만든다. 무료 공개지도, 한국 기본 화면, TOP10/TOP20 선택(기본10), 종합형 비교, 에디토리얼+Frutiger Aero가 현재 합의다. 새로운 사용자 결정은 이 기준보다 우선한다.

## 시작과 팀

현재 소스·AGENTS.md·배포 상태를 먼저 읽는다. 제품 변경에는 [결정·비교 기준](references/product.md), 데이터/외부 서비스 변경에는 연구 담당이 작성한 근거 문서와 해당 서비스의 최신 공식 정책을 확인한다. 과거 명세의 제안은 사용자 승인으로 간주하지 않는다.

팀 요청이 있으면 필요한 역할을 실제 별도 에이전트로 운영한다. 단순 수정은 불필요하게 팀을 늘리지 않는다.

- 조정·제품: 최신 선택과 범위, 비교항목, 미확정 질문, 완료 기준을 정리한다.
- 데이터·연동 조사: 공식 문서와 데이터 출처·시각·라이선스·접근제한을 기록한다. 다음 담당에게 검증된 사실, 결측, 금지/제한, 제안을 구분해 넘긴다.
- 디자인·구현: 승인된 기능을 구현하고 실제 브라우저에서 검증한다. 변경 파일·동작 증거·미구현을 넘긴다.
- 독립 검토: 제작자가 아닌 담당이 결과 화면과 데이터 경계를 확인한다. 발견한 결함·심각도·재현 절차·잔여 한계를 기록하고 수정 후 해당 결함을 다시 확인한다.

## 제품 불변 조건

지도는 왼쪽, 비교 결과는 오른쪽이다. 모바일에서는 지도를 먼저 배치한다. 이동은 EXPLORER, 멈춤은 CATCH이며 분석 버튼 클릭 당시 bounds를 고정한다. 오래된 응답이 새 분석을 덮지 않도록 취소 또는 요청ID를 사용한다. 빈 결과, 미조회, 오류, 제한, 일부 응답을 구분한다. 과대영역은 범위를 좁히도록 안내한다.

Navigator는 현재 좌표·줌·움직임과 마지막 분석 영역·시각, 원천 발견 수, 중복 제거 수, 표시 수, 추가 후보 수, 결측 수를 구분한다. 이동 후 새 조회가 없다면 현재 영역의 수를 “미조회”로 표시한다. 원천에서 발견한 수를 실제 전체 골프장 수라 부르지 않는다.

무료 공개지도 우선이 Google Earth 사용 확정을 뜻하지 않는다. 공개 Overpass를 대중 공개앱의 상시 백엔드로 의존하지 않는다. 운영은 갱신일·출처가 있는 캐시 JSON 또는 자체 endpoint를 분리한다. 제한적 공개 endpoint 시연은 그 성격과 실패 가능성을 표시하고 자동 반복 조회를 피한다. 타일·데이터 제공자의 표시·캐시·이용 정책을 확인한다.

## 데이터와 TOP10/20

실제 확인하지 않은 가격·리뷰·순위·예약상태를 생성하지 않는다. 값에는 출처 URL, 확인시각, 적용일/조건, 단위, 확인/부분확인/미확인/해당없음을 보존한다. 결측은 0점이 아니다. 지도 객체만 있으면 “지도 후보 최대10/20 · 순위 미산정”으로 표시하고 후보 선택·정렬 기준을 설명한다. 상한 미만이면 실제 수만 보여준다.

비용·코스·접근성·근거 충실도의 종합형이 기본이다. 가중치 30/30/25/15는 사용자 승인사항이다. 정규화 척도·비교 조건을 공개하고 근거가 충분할 때만 계산하며 승인된 가중치로 결측을 덮지 않는다. 날짜·인원별 1인 총비용, 최대4곳 비교, 관심 골프장 저장은 단계적 반영이 승인되었다. 승인과 구현 완료는 구분한다. 리뷰 검색 링크를 우선 제공하며 자동 수집·요약 API는 정책·제휴 허용범위 확인 후 별도 구현한다. 정보 충실도와 코스 품질은 별개다. 리뷰는 제공처·척도·표본수·기간을 표시하며 출처 간 단순 평균을 피한다. 장단점은 근거 사실과 편집 해석을 구분한다.

최소 25개 이상 비교항목을 명세에서 선택한다. 그린피는 주중/주말, 적용일·티타임·통화·세금·카트·캐디·팀/인당 과금을 구분한다. 인원과 필수비가 불명확하면 총액을 확정하지 않는다. 직선거리를 이동거리·소요시간으로 표현하지 않는다.

## 디자인과 내보내기

잡지형 타이포·선명한 위계·여백 위에 물빛·연두·물방울의 Aero 포인트를 쓴다. 과한 유리판 대시보드로 채우지 않는다. 실제 사진은 권리·크레딧을 확인한다. 사진이 없으면 “지형 그래픽 · 실제 전경 아님”이라고 표시한 그래픽을 사용한다. 생성 풍경을 실제 골프장 전경으로 제시하지 않는다.

HTML 저장본은 영역·분석시각·출처·결측·비교 기준을 보존하고 독립적으로 읽히게 한다. 외부 문자열은 이스케이프하며 링크는 허용한 http/https 등 용도별 안전한 스킴만 쓴다. mailto는 메일 초안 기능이며 발송·첨부 완료로 보고하지 않는다. 앱 URL 복사는 결과 저장·공개발행과 구분한다.

공식 예약 URL을 확인한 경우만 “공식 예약”이라 표시한다. 홈페이지와 제3자 예약서비스는 구별한다. 실시간 티타임·직접 예약 연동은 공식 API/제휴 조건과 비용 확인 후 사용자가 선택한 범위에서 구현한다.

## 검증·공개

실제 브라우저에서 지도 이동/줌, bounds 고정, 10/20 선택, 재분석·취소, 결측·오류, HTML 저장·링크 복사·메일 초안을 확인한다. 넓은 화면과 390px 모바일에서 넘침·지도 조작·키보드 포커스·글자 대비·모션 감소를 확인한다. 스크린샷은 실제 결과를 검토한 증거이며 파일 생성만으로 시각 QA 완료를 주장하지 않는다.

GitHub 공개는 현재 사용자의 공개 지시와 승인 범위를 따른다. 저장소에 비밀·개인정보·임시 산출물을 포함하지 않는다. 소스 push→Actions→Pages 자동 반영을 구성하고 저장소 공개 여부, 워크플로 성공, 실제 외부 URL 응답과 핵심 기능을 각각 확인한다. 배포 로그 성공과 외부 사용 가능은 별도 판정이다. 자동 배포가 탐색 결과의 자동 공개를 뜻하지 않는다.

완료 보고에는 구현/미구현, 확인한 URL·시각, 실행한 검증과 관찰 결과, 외부 의존을 적는다. 자가 점수만으로 독립 검토나 완료를 대체하지 않는다. 미승인 추가 기능·가중치 변경·유료 API·자동메일·결과 공개저장은 제안과 확정을 구분하고, 새 권한이 필요한 단계는 구체적 결과를 준비한 뒤 협의한다.
