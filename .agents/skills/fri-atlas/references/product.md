# 결정·비교 기준

기준일: 2026-10-21. 향후 사용자의 명시적 변경을 우선한다. 구현 완료를 기록하는 문서가 아니라 제품 기준이다.

## 확정

무료 공개지도 우선, 한국 기본 세계 탐색, 지도 좌/비교 우, 기본 TOP10·TOP20 선택, 비용·코스·접근성·근거 충실도의 종합형. 가중치 30/30/25/15 적용 승인. 날짜·인원별 1인 총비용, 최대4곳 비교, 관심 골프장 저장은 단계 반영 승인. 리뷰는 검색 링크 우선이며 수집 API는 미구현·정책 확인 대상이다.

## 비교 사전: 40항목 확장 설계

아래 40항목은 확장 설계다. 실제 비교표는 OSM 후보 36필드, 공식 카탈로그 41필드로 구성한다. 미확인 값을 표시하는 UI 구현과 실제 값 확보는 별개다.

각 값에 value/unit/source_url/checked_at/applicable_date/status를 둔다. status는 확인/부분확인/미확인/해당없음이다.

- 정체·근거: 이름·현지명, 국가·주소, 좌표, 공식 홈페이지, 공식 예약 URL, 출처·확인시각, 운영상태, 자료 충실도.
- 비용: 통화, 주중 그린피, 주말·공휴일 그린피, 적용일·시즌·티타임, 카트비·과금단위, 캐디비·과금단위, 세금·필수비, 대여비, 취소·환불 조건, 1인 예상 총액.
- 코스: 홀수, 파, 전장·티 기준, 코스 유형, 지형·고저차, 공식 난이도 지표, 그린·잔디, 설계자, 연습시설, 클럽하우스·식음·샤워.
- 접근·조건: 지도열기, 선택 기준점 직선거리, 대중교통·공항 안내, 방문자·회원 제한, 최소 인원, 보행·카트 조건, 접근성 편의, 운영·예약 가능 범위.
- 평가·시각: 리뷰 출처·표본수·기간, 근거 기반 장점, 근거 기반 유의점, 전경 이미지·권리·크레딧.

1인 총액 = 그린피 + 1인 필수비 + (팀 단위 카트·캐디비 ÷ 입력 인원) + 해당 세금. 세금 중복·선택비 혼입을 방지하고 필수 값이 없으면 산출 불가다. 서로 다른 시즌·날짜·티타임을 동등한 가격처럼 비교하지 않는다.

## 디자인

배경 #EDF5ED, 본문 #133F3A, 보조 #526D67, 종이 #FFFFFF, 잔디 #507D3E, 물빛 #53C5DC, 청록 #075B62, 햇살 #E6F477. 본문 system-ui/Noto Sans KR 계열, 영문 대제목 Georgia 계열. 여백 8/16/24/40/64px, 본문16px·줄높이1.6, 카드 반경18px. 900px 이하에서는 지도 45vh를 먼저 보여준다. 장식은 읽기·지도 조작·대비를 방해하지 않는다.

카피 예시: “오늘의 페어웨이를 잡다.”, “EXPLORER · 좋은 풍경을 찾는 중”, “CATCH · 이 풍경, 잡았어요”, “ANALYSIS ATLAS · 이 영역 분석”. 사진 없는 그래픽은 실제 코스 전경이 아니라고 표시한다.

## 미확정·범위 밖

실시간 티타임·예약 API, 유료 지도·평가 데이터, 자동 이메일, 결과의 서버 저장·자동 공개, 여행 메모·오류 제보·다국어·확인시각 필터는 별도 선택 대상이다. 공개 계정·결제·예약대행·무단 크롤링·리뷰 복제는 승인된 MVP에 포함하지 않는다.
