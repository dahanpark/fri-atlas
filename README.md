# FRI ATLAS

한국에서 시작하는 골프 지도·비교 HTML 앱. [공개 앱](https://dahanpark.github.io/fri-atlas/) / [공개 저장소](https://github.com/dahanpark/fri-atlas). 공개 배포 상태는 Actions와 실제 URL을 별도로 확인합니다.

## v2 사용 방법

지도를 옮기거나 확대하고 멈추면 화면 안의 **모든 위치 표본**이 자동으로 표시됩니다. 이 이동은 다운로드한 전국 JSON을 브라우저에서 필터링하며 외부 검색 API를 호출하지 않습니다. **ANALYSIS ATLAS**는 누른 시점의 영역을 고정하여 오른쪽에 TOP10/TOP20 후보를 비교합니다. 마커는 TOP 상한과 무관합니다. 마커를 누르면 코스 카드가 열리고 카드 이름을 누르면 지도에서 선택합니다.

추천은 검증된 네이버 평점 우선입니다. 현재 개별 평점은 미연결이므로 공식18홀요금 확인→스크린·연습·파크로 명시된 후보 후순위→이름순으로 표시하며, 연습/스크린/파크로 명시된 이름·무명은 뒤로 보냅니다. 이는 정보 확보순이며 코스 품질순위가 아닙니다. 주중·주말 일반 그린피와 서울/부산 도로거리 확보 후보순도 선택할 수 있습니다. 결측은 — 이고 뒤로 정렬합니다.

서울시청(37.5665,126.9780)·부산시청(35.1796,129.0756) 기준의 **OSRM 도로 추정**은 ANALYSIS를 직접 누를 때 현재 표시 후보 최대20곳만 조회합니다. 경로 성공·실패·시간초과와 실제 선택 정렬명을 분석상태에 보존합니다. 초기 자동 분석과 지도 이동은 경로 API를 호출하지 않습니다. 실시간 교통을 반영하지 않으며 실제 출입구가 아닌 대표점일 수 있습니다. 도로거리 확보 후보순은 전국 전체 최단거리순이 아닙니다. 실패·미조회 경로는 — 와 외부 길찾기를 제공합니다. 20초 취소, 2초 요청 간격, 동일 목적지 캐시를 적용했습니다.

## 자료 범위

전국 위치 파일은 OSM `leisure=golf_course` 등록 개체1119개 스냅샷입니다. 실제 영업 골프장1119곳을 뜻하지 않습니다. 이름 없는 개체264개, 연습·스크린·파크 등 혼재, 동일 운영코스 중복과 누락 가능성이 있으며 공식 운영 명부 대조가 완료되지 않았습니다. 별도 공식자료4곳 중3곳은 source ID/구명칭 근거로 결합하고, 미매칭 해비치제주는 공식지도점으로 별도 개체를 추가합니다. 전국지도에는 최대1120개 표본이 있을 수 있습니다.

서울 해비치는 원 OSM대표점과 공식지도점이 달라 공식지도점을 표시하고 이전 대표점을 근거에 보존합니다. 해비치제주는 공식지도점을 사용하며 인접 부영CC에 가격을 붙이지 않습니다. 공식지도점도 실제 입구로 보증하지 않습니다.

NAVER 지역검색 API는 방문 별점·후기본문 API가 아니므로 개별 네이버 평점·표본수는 미연결입니다. 네이버 장소 검색 링크를 제공합니다. 아난티코드의 짧은 비네이버 후기표본은 제공처를 표시하고 후기 내용은 외부 HTML로 반출하지 않고 제공처·자료종류·표본수·대표성·확인일·적용한계는 보존합니다. 평가를 창작하거나 타사평점을 네이버로 표시하지 않습니다.

의령친환경골프장 사진1건은 실제코스 이름 대조와 CC BY-SA4.0 사용권·저자 표시를 적용했습니다. 다른 코스는 사진이 없으며 지형아이콘은 실제 전경이 아닙니다. 이미지 로딩 실패 시 아이콘으로 돌아갑니다. 사진은 외부 위키미디어에서 로딩합니다.

## 저장·비교·예약

최대4곳 비교, 예정일·인원, 브라우저 관심목록을 지원합니다. 관심목록과 비교는 코스 스냅샷으로 보존합니다. 선택일 확정요금·세금·필수비가 빠지면 총액은 산출 불가입니다. 복수18홀 일반요금은 최저~최고 범위, 단일 조건은 해당 일반요금으로 표시합니다. 가격 정렬 키만 최저값을 쓰며 날짜별 실시간 견적이 아닙니다. 상세 근거에 과금단위·홀수·시행일·접수일 기준을 보존합니다.

독립 HTML에는 간결 비교표·별도4곳·날짜/인원·산출불가 사유·분석영역/시각·현재목록과 별도4곳의 ID 합집합 원천 상세가 남습니다. TOP20 본문은 코스별 행 중심5열표, 별도4곳은 나란히 비교표입니다. 지도 스크립트는 없습니다. 화면 링크는 위치·줌·정렬·검색어·상한·날짜·인원을 공유하며 결과를 서버에 공개 저장하지 않습니다. mailto는 작성창만 열고 HTML 첨부·발송은 사용자가 합니다.

공식 검증 예약URL만 직접예약으로 표시합니다. 일반 홈페이지와 XGOLF·티스캐너 일반 서비스, 카카오골프예약 앱 런처는 해당 라벨로 구분하며 개별코스 예약 API가 아닙니다. 예약·결제·취소를 자동 수행하지 않습니다.

## 실행·검증·배포

Node.js가 있으면 `node server.mjs` 후 `http://127.0.0.1:4173` 접속. 설치·빌드가 필요 없습니다. `node --test tests/core.test.js tests/v2.test.js` 실행. 각 `dist/*.js`와 `server.mjs`를 `node --check`로 검사합니다. Leaflet·지도·글꼴·이미지·경로에 인터넷 연결이 필요합니다.

main push → 모든 JS문법검사·핵심테스트 → dist만 GitHub Pages 배포. 사용자의 결과와 관심목록은 GitHub에 자동 업로드하지 않습니다. 외부 API 장애와 앱 배포 장애를 구분합니다. 비밀키는 없습니다.

한국 밖은 전 세계 지도 탐색과 제한적 화면 검색을 지원합니다. 해외 분석은 작은 영역에서만 페이지당1회 Overpass 요청, 취소·타임아웃과 오래된 응답 방지를 적용합니다. 대중 서비스의 상시검색·경로에는 자체/계약 공급자가 필요합니다. 공용 인프라에는 SLA가 없습니다.
