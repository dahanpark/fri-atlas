# FRI ATLAS

현재 v5: **18홀 이상으로 확인한 정규 코스 28곳**을 비교합니다. 연습장·스크린·파크·9홀·홀수/등록유형 미확인 객체는 표시하지 않습니다. 전국 골프장 전체를 확보한 상태는 아닙니다.

2026년 MK·한국리서치 조사평가 6코스의 동일 1000점 척도를 정렬에 반영합니다. NAVER/Google 별점이 아니며 전체 조사 2,316명을 코스별 응답수로 표시하지 않습니다. 서울시청·부산시청 실제 OSRM 응답 캐시는 28곳 모두에 연결되며 날짜·교통미반영·제주 해상연계 조건을 보존합니다.


한국에서 시작하는 골프 지도·비교 HTML 앱. [공개 앱](https://dahanpark.github.io/fri-atlas/) / [공개 저장소](https://github.com/dahanpark/fri-atlas). 공개 배포 상태는 Actions와 실제 URL을 별도로 확인합니다.

## v3 사용 방법

지도를 옮기거나 확대하고 멈추면 화면 안의 **모든 위치 표본**이 자동으로 표시됩니다. 이 이동은 다운로드한 전국 JSON을 브라우저에서 필터링하며 외부 검색 API를 호출하지 않습니다. **ANALYSIS ATLAS**는 누른 시점의 영역을 고정하여 오른쪽에 TOP10/TOP20 후보를 비교합니다. 마커는 TOP 상한과 무관합니다. 마커를 누르면 코스 카드가 열리고 카드 이름을 누르면 지도에서 선택합니다.

추천은 공식 18홀 요금과 코스 소개·후기자료 확인 우선입니다. 명시된 스크린·연습·파크와 무명은 뒤로 표시합니다. 이는 정보 확보순이며 코스 품질순위가 아닙니다. 주중·주말 그린피와 서울/부산 도로거리 확보 후보순도 선택할 수 있습니다. 결측은 — 이고 뒤로 정렬합니다. 미연결 네이버 평점·검색 링크·보고서 열은 사용자 요청으로 삭제했습니다.

서울시청(37.5665,126.9780)·부산시청(35.1796,129.0756) 기준의 **OSRM 도로 추정**은 ANALYSIS를 직접 누를 때 현재 표시 후보 최대20곳만 조회합니다. 경로 성공·실패·시간초과와 실제 선택 정렬명을 분석상태에 보존합니다. 초기 자동 분석과 지도 이동은 경로 API를 호출하지 않습니다. 실시간 교통을 반영하지 않으며 실제 출입구가 아닌 대표점일 수 있습니다. 도로거리 확보 후보순은 전국 전체 최단거리순이 아닙니다. 실패·미조회 경로는 — 와 외부 길찾기를 제공합니다. 20초 취소, 2초 요청 간격, 동일 목적지 캐시를 적용했습니다.

## 자료 범위

전국 위치 파일은 OSM `leisure=golf_course` 등록 개체1119개 스냅샷입니다. 실제 영업 골프장1119곳을 뜻하지 않습니다. 이름 없는 개체264개, 연습·스크린·파크 등 혼재, 동일 운영코스 중복과 누락 가능성이 있으며 공식 운영 명부 대조가 완료되지 않았습니다. 기존 공식자료4곳 중3곳은 source ID/구명칭 근거로 결합하고, 미매칭 해비치제주는 공식지도점으로 별도 개체를 추가합니다. v3에서는 곤지암GC·360도CC·가평베네스트GC·가야CC의 공식요금을 정확한 OSM ID에 추가하여 공식요금 코스는 8곳입니다. 그린힐CC·감곡CC는 공식 접근차단으로 가격을 채택하지 않았습니다. 전국지도에는 최대1120개 표본이 있을 수 있습니다.

서울 해비치는 원 OSM대표점과 공식지도점이 달라 공식지도점을 표시하고 이전 대표점을 근거에 보존합니다. 해비치제주는 공식지도점을 사용하며 인접 부영CC에 가격을 붙이지 않습니다. 공식지도점도 실제 입구로 보증하지 않습니다.

공개후기 원문을 읽은 표본만 짧게 자체 요약합니다. 제공처·자료종류·표본수·대표성·확인일·적용한계를 보존하며 전체 이용자 총평으로 주장하지 않습니다. 반출허용 없는 후기내용은 HTML에서 제외합니다. 공식 소개 기반의 세 문장 특장점은 이용후기와 구분합니다. 곤지암GC·그린힐CC·360도CC는 각 방문기 2편을 열람했습니다. 곤지암 2편은 동일 리뷰어로 보이는 재방문 기록이므로 독립된 2명 평가로 세지 않습니다.

의령친환경골프장 사진1건은 실제코스 이름 대조와 CC BY-SA4.0 사용권·저자 표시를 적용했습니다. 추가 대표이미지는 코스 ID를 대조한 출처만 사용하며 지형아이콘은 실제 전경이 아닙니다. 공식 og:image 공유 미리보기는 화면에서만 원격 표시하고 HTML은 공식페이지 링크로 바꿉니다. 곤지암GC·그린힐CC·360도CC는 한국관광공사 TourAPI 대표이미지를 출처표시·변경금지 조건으로 화면 원격 참조합니다. 개별 공공누리 1·3 유형은 미확인하여 원본 구도를 contain으로 유지하며 HTML에는 사진 대신 공식 코스 페이지 링크를 남깁니다. 외부 반출허용을 임의로 인정하지 않습니다. 이미지 로딩 실패 시 아이콘으로 돌아갑니다. 사진은 외부 위키미디어·한국관광공사에서 로딩합니다.

## 저장·비교·예약

오른쪽 결과목록만 독립 스크롤하며 바로 아래에 선택 비교표를 표시합니다. 비교 추가 시 표가 즉시 갱신되고 표로 이동합니다. 모바일에서는 비교표 내부만 가로 스크롤합니다. 최대4곳 비교, 예정일·인원, 브라우저 관심목록을 지원합니다. 관심목록과 비교는 코스 스냅샷으로 보존합니다. 선택일 확정요금·세금·필수비가 빠지면 총액은 산출 불가입니다. 복수18홀 일반요금은 최저~최고 범위, 단일 조건은 해당 일반요금으로 표시합니다. 가격 정렬 키만 최저값을 쓰며 날짜별 실시간 견적이 아닙니다. 360도CC는 2026-10-19~25 한정표에서 비회원 주중17~20만원/주말23~27만원을 산출한 범위로 가격셀에도 기간을 표시하며 다른 기간에 적용하지 않습니다. 상세 근거에 과금단위·홀수·시행일·접수일 기준을 보존합니다.

독립 HTML에는 간결 비교표·별도4곳·날짜/인원·산출불가 사유·분석영역/시각·현재목록과 별도4곳의 ID 합집합 원천 상세가 남습니다. TOP20 본문은 코스별 행 중심4열표, 별도4곳은 나란히 비교표입니다. 지도 스크립트는 없습니다. 화면 링크는 위치·줌·정렬·검색어·상한·날짜·인원을 공유하며 결과를 서버에 공개 저장하지 않습니다. mailto는 작성창만 열고 HTML 첨부·발송은 사용자가 합니다.

공식 검증 예약URL만 직접예약으로 표시합니다. 일반 홈페이지와 XGOLF·티스캐너 일반 서비스, 카카오골프예약 앱 런처는 해당 라벨로 구분하며 개별코스 예약 API가 아닙니다. 예약·결제·취소를 자동 수행하지 않습니다.

## 실행·검증·배포

Node.js가 있으면 `node server.mjs` 후 `http://127.0.0.1:4173` 접속. 설치·빌드가 필요 없습니다. `node --test tests/core.test.js tests/v2.test.js` 실행. 각 `dist/*.js`와 `server.mjs`를 `node --check`로 검사합니다. Leaflet·지도·글꼴·이미지·경로에 인터넷 연결이 필요합니다.

main push → 모든 JS문법검사·핵심테스트 → dist만 GitHub Pages 배포. 사용자의 결과와 관심목록은 GitHub에 자동 업로드하지 않습니다. 외부 API 장애와 앱 배포 장애를 구분합니다. 비밀키는 없습니다.

한국 밖은 전 세계 지도 탐색과 제한적 화면 검색을 지원합니다. 해외 분석은 작은 영역에서만 페이지당1회 Overpass 요청, 취소·타임아웃과 오래된 응답 방지를 적용합니다. 대중 서비스의 상시검색·경로에는 자체/계약 공급자가 필요합니다. 공용 인프라에는 SLA가 없습니다.

브랜드명만으로 시설 유형을 단정하지 않습니다. 골프존카운티 선산은 공식 코스 소개 근거로 코스로 표시하고, 나머지는 명시적인 스크린/연습/파크 또는 개별 검증이 없으면 유형 미검증입니다. 경로 근거에는 서울·부산 각각의 실제 응답시각·제공처·목적지 대표점·도로스냅 거리/경고를 보존하며 캐시·관심·비교의 시각을 새 분석시각으로 바꾸지 않습니다.

그린힐CC에는 한국관광공사 공식 관광안내의 참고요금을 추가했습니다. 골프장 직접확인 요금8곳과 구분하며 적용 기준일·홀/단위 미확인을 가격 옆에 표시합니다. 이 참고값은 공식요금 정렬과 확정 총액 계산에서 제외합니다.

## 2026-10-23 화면 개선
비교 패널을 결과목록 아래 고정 영역으로 유지하며, 화면 마커가 1~49개이면 지도 이름표를 상시 표시합니다. 카드의 배치 근거는 자료 확보 여부를 뜻하며 이용자 평점이나 품질순위가 아닙니다.
