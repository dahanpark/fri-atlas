# FRI ATLAS v2 구현 기록

기준일 2026-10-22. 코드 구현과 실제 브라우저·공개 배포 검증은 구분한다. 공개 검증은 팀장 기록을 참조한다.

## 변경

app.js는 상태와 지도, data.js는 전국자료/정렬/명시매칭, views.js는 간결 카드/비교표/HTML, routing.js는 OSRM table 호출로 분리했다. 기존 core.js의 안전문자열·URL·비용·상세근거 계약을 유지한다. 공급자 선택 UI는 제거했다.

전국수집 담당의 courses-kr.json 원천1119개를 정지후300ms debounce로 로컬 필터링한다. Canvas circleMarker를 사용해 현재 화면의 모든 위치 표본을 표시한다. 지도마커는 TOP10/20 및 검색어/관심 필터로 잘리지 않는다. ANALYSIS 버튼의 영역스냅샷만 최대10/20개 비교 목록으로 만든다. 이동해도 기존 분석영역은 보존한다. 마커 선택은 카드 프리뷰와 하이라이트를, 카드 선택은 지도이동과 마커 선택을 연결한다.

원천1119개에는 무명264개, 연습·스크린·파크 태깅혼재가 있다. 실제 운영코스 전체목록이라고 부르지 않는다. source ID 정확대조 서울·코드2곳과 별도 구명칭근거 아난티제주1곳을 공식자료에 연결한다. 해비치제주는 인접OSM코스에 추정병합하지 않고 공식지도점의 별도개체로 표시한다. 합계지도표본은1120개 가능. 서울은 공식지도점37.61344,127.28962로 표시하며 원OSM대표점과 출처를 상세근거에 보존한다. 제주 공식점33.358839,126.728099도 입구 보증이 아니다.

카드와4비교는 네이버별점/표본수, 주중·주말18홀/1인 그린피, 캐디피와 과금단위, 위치/좌표, 서울·부산도로 추정, 장점·유의각2개이내와 예약링크를 간결표시한다. 상세조건은 근거펼침 한곳에 모았다. 네이버별점은 미연결이므로 검색링크와 — 로 표시한다. 아난티코드의 비네이버짧은후기표본은 제공처를 표시하며 exportAllowed=false로 후기내용은 HTML에서 제외하고 제공처/AI요약·표본수/대표성/확인시각/한계메타데이터만 보존한다. 본문복제·네이버평가로의 이름변경은 없다. 아난티코드 공식 비회원18홀26/29만원, 캐디15/카트11만원은 새로운 공식조사자료의 시행일과 함께 표시한다. 복수일반요금은 최저~최고 범위이고 단일조건은 해당일반요금을 표시한다. 정렬키는 최저값이며 실시간견적이 아니다.

추천순은 확인네이버평점→공식18홀요금확인→명시된스크린/연습/파크후순위→이름이며 명시연습/스크린/파크와무명은 후순위다. 정보확보순이고 품질순위가 아니다. 주중/주말가격·도로거리 정렬은 결측을 뒤로 보낸다. 도로거리순은 경로가 확보된 표시후보내 순서이며 전체지도 최단거리순이 아니다.

서울시청/부산시청2개 출발점에서 선택후보최대20곳으로 OSRM table1회 요청한다. 미터→km, 초→분 변환. 20초취소, 2초요청간격, 같은목적지캐시, request ID 무효화를 적용한다. 지도이동과 초기자동분석은 외부경로조회하지 않는다. 지도점에서 도로스냅1km초과시 *표시, 경로없음/실패는 —와외부카카오길찾기. 실시간교통미반영·도로추정·공용API무SLA를 안내한다.

의령친환경골프장1건 실제사진은 코스명/원천객체645101379와 대조한 CC BY-SA4.0 이미지다. 저자Hahaha2337·사진출처·라이선스·크기조정을 표시한다. 이미지오류시 지형아이콘으로 대체한다. 다른 임의골프사진은 넣지 않았다. XGOLF/티스캐너는 일반서비스, 카카오는예약앱런처로 표시하고 직접코스예약/API라 부르지 않는다.

HTML은 짧은비교표·날짜/인원·선택4곳과 비용산출불가사유·원천조건·안전웹사이트링크·허용사진을 보존하며 지도스크립트가 없다. 관심저장/비교스냅샷과 전부비우기, 취소·오래된응답방지·이스케이프·URL검사를 유지했다. 헤로를줄여지도에 실용높이를 주고 Aero+에디토리얼 시각언어를 정돈했다.

## 검사

전체 dist JS·서버 문법검사를 시행한다. 핵심테스트26개 통과: 기존8개와 전체viewport55마커/TOP10·20독립, 평점·가격결측, 엄격ID매칭, OSRM단위/null경로, v2보고서조건/권한없는후기반출차단, 실제전국1000개초과자료, 이동연속이벤트합치기/취소, 추천fallback, 사진코스/권리검사. 테스트는 외부실호출을 대체하지 않는다. 실제브라우저 지도이동·마커카드연결·도로응답·사진·390px검증과 공개asset일치는 팀장/독립리뷰 결과로 확정한다.

## 남은 경계

NAVER 개별평점/후기API·완전한운영명부대조·전국모든요금/사진·실시간티타임·제휴예약API는 미연결이다. 공용OSRM/Overpass를 대중상시백엔드로 보장하지 않는다. OSRM경로는 대표점스냅/선박경유 등 실제운행조건을 보장하지 않는다. 가격·좌표·브랜드명은 출처별 갱신시점이 다르므로 별도검증이 필요하다. 해비치제주 전국원천의 동질코스미확인은 추가조사 대상이며 인접코스와 합치지 않았다.

추가 QA 보강: 사진 matcher의 누락 URL 동등비교를 제거하고 사진에 courseId/courseName을 보존해 현재·과거저장자료 양쪽에서 코스동일성을 재검사한다. 전국/공식자료 전수에서 의령1개만 사진첨부됨을 검증했다. 복수18홀 일반요금은 최저~최고 범위로 카드·비교·HTML에 공통표시하며 정렬키는 최저값을 유지한다. OSRM제공/지도오류수정 링크를 지도 출처란에 표시한다.

1차 독립검토 보강: HTML근거는 현재목록과 별도4선택의 ID합집합으로 한 번씩 보존한다. TOP20은5열행목록으로 만들고 별도4비교만 나란히 배치한다. analysis-state.js에서 경로성공/부분/미제공/실패/시간초과를 구분해 snapshot과 최종정렬안내에 유지한다. 후기종류·표본·대표성·한계·확인일을 펼침에 모았고 사진CC직접링크·크레딧·변경표시 및 사진상태를 코스별로 동기화했다. 회귀26개와 전체JS문법검사통과. 실제브라우저390px·의령사진로드/크레딧·관심/비교는 팀장QA확인, 새독립검토와공개배포검증은 별도다.

추가 결함수정 VF1/VF2: 골프존 브랜드 단독 스크린 분류를 제거했다. 선산1곳만 검토서 공식코스 근거로 확인하며 다른13곳을 정규코스로 새로 단정하지 않는다. 미검증 유형은 명시 특수시설의 분류 후순위와 구분한다. 경로 응답 목적지와 실제 checkedAt/provider/스냅 경고를 근거에 보존하고 TOP·비교합집합 HTML에도 포함한다. 기존 새독립전체검토의 불합격 평균9.2 판정은 변경하지 않는다. 이번 수정은 두 결함 확인용이며 원문 모든 데이터 확보 완료를 뜻하지 않는다.
