## 구현

- `.shortlist-panel`만 독립 스크롤, `#planningPanel`은 오른쪽 바로 아래 별도 흐름. 첫 비교 추가 시 표로 이동하고 키보드 조작 때 포커스, 모션감소 환경에서 즉시 이동. 모바일 비교표 자체 가로 스크롤.
- 카드 NAVER 미연결 링크·비교행·보고서 열·추천근거를 제거. 기본은 공식요금·코스소개·확인후기 정보 확보순이며 코스 품질점수 아님. 가격·도로거리의 결측 후순위 보존.
- 새 공개 파일 `dist/v3-fees.json`/`v3-course-stories.json`, ID결합 모듈 `enrichment-v3.js`. 조사 원문 output파일은 변경하지 않음. 주중·주말 min/max를 보존하고 360도CC 2026-10-19~25 한정조건을 카드·비교 가격셀에 직접 표시. 그린힐 공식요금은 접근차단으로 — 유지.
- 곤지암·360·가평베네스트·가야 공식요금 추가. 가평·가야 캐디 단위 불명은 null/단위미확인, 곤지암·360은 팀당. 원본요금 URL과 과금조건 상세 보존. 선택일 확정가·필수비 부족 시 총액 산출 불가.
- 곤지암·그린힐·360 각각 공식소개3문장, 방문후기2편 자체요약(장점2/유의2), 모든 원문 링크·시점·표본/대표성 한계. 곤지암 동일 리뷰어 가능성을 명시. 반출불허 후기 요약은 HTML제외.
- TourAPI 대표사진3개는 해당ID만 화면 원격참조 채택, 출처/사용조건 링크·저자 표시, contain으로 원본구도 보존. 원문 renderVerified=false는 루트 실브라우저 확인 전 유지. HTML은 사진이미지 대신 공식이미지 보기 링크. 기존 의령 CC사진은 HTML허용·직접라이선스 보존. 사진을 타코스에 붙이지 않음.
- 화면/보고서 모두 비교헤더 작은 썸네일, 공식소개와 후기 구분. HTML detail은 현재TOP와별도4곳ID합집합·경로실조회시각·권리제한 유지.
