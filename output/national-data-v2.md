# FRI ATLAS 전국 지도 데이터 수집·대조

한 줄 요약: 대한민국 행정영역의 OpenStreetMap 골프장 태그 객체 1,119개를 한 번 수집해 로컬 인덱스로 만들었다. 실제 영업 골프장 1,119곳 또는 국내 모든 골프장을 확보했다는 뜻은 아니며, 공식 명부와의 전국 일대일 대조는 완료되지 않았다.

## 1. 확인된 원천과 수집 범위

- 산출물: `dist/courses-kr.json`, 재생성 도구 `scripts/update-courses.mjs`.
- 원천: [OpenStreetMap](https://www.openstreetmap.org/copyright), [Overpass](https://overpass-api.de/api/interpreter).
- 수집 완료 시각: 2026-10-22T03:55:12.275Z(다운로드 원문 파일 시각). OSM 데이터베이스 기준 시각은 2026-10-22T03:53:56Z이며 JSON `source.osmBaseTimestamp`에 보존했다. `generatedAt`은 로컬 재정규화 시각으로 원천 수집 시각과 구별한다.
- 범위: `ISO3166-1=KR`, `admin_level=2` 행정영역 안의 `node`, `way`, `relation` 중 `leisure=golf_course`. 한국 전체를 한 번 질의했으며 지도 이동 때 외부 API를 호출하는 방식이 아니다.
- 질의: `[out:json][timeout:120];area["ISO3166-1"="KR"]["admin_level"="2"]->.kr;nwr["leisure"="golf_course"](area.kr);out center tags;`.
- 응답 다운로드: 254,795바이트. 원문을 `.tmp/data/overpass-golf-kr.json`에 보관하고 SHA-256을 공개 JSON에 기록했다. 앱에서는 공개 정규화 스냅샷을 읽고 현재 화면 범위로 필터링하면 된다.

수집 사실과 품질 판단을 구분한다. 전국 행정영역을 질의했다는 것은 질의의 지리적 범위이며, 지도에 미등록인 시설을 확보했다는 뜻이 아니다. 태그 누락·오분류·명칭 변경·별도 코스 객체가 존재할 수 있다. 한국의 골프장 운영 명부와 OSM의 시설 경계 데이터는 집계 단위부터 다르다.

좌표 범위는 위도 33.2495825~38.3199908, 경도 126.1580261~129.4842863다. 모든 객체에 숫자 좌표가 있으며 대한민국 검사용 넓은 범위(위도32~39, 경도124~132) 안이다. 이 검사는 이상 좌표를 거르는 안전 검사이고 행정경계 내부성을 다시 판정하는 지오펜스 검사는 아니다. 실제 경계 포함 여부는 Overpass 대한민국 area 질의에 의존한다.

주소에 시도·도시 태그가 있는 객체는 103개이고 1,016개에는 이 구분이 없다. 서울·경기·충청·경상·전라·강원과 광역시 주소 태그가 보이지만, 주소 태그 통계로 시도별 완전성을 계산할 수 없다. 제주 좌표와 육지 북단·동서 범위가 포함된다는 사실까지만 지리적 확장으로 확인했다. 시도별 공식 운영 시설 수와의 정량 커버리지 비율은 미산정이다.

명칭에 `연습`, `스크린`, `골프존`, `driving`, `screen`이 포함된 객체가 200개다. 이것은 이름 패턴 감사 결과이며 시설 유형을 검증한 수치가 아니다. `leisure=golf_course`만으로 18홀 정규 골프장 또는 예약 가능한 영업 시설이라고 단정하면 안 된다. 요청 범위에 따라 원천 객체는 유지하고 명칭만으로 삭제하거나 다른 타입으로 덮어쓰지 않았다. 무명 264개도 좌표를 지어내지 않은 원천 객체이며 `이름 미등록 (type/id)`라는 표시 이름을 부여했다. 분석 추천 순위에 무명을 앞세우지 않도록 구현 담당에게 전달했다.

추가 명칭 감사에서 `파크골프` 또는 `park golf` 패턴은 20개, `실내` 또는 `indoor` 패턴은 3개다. 각 객체 ID는 `audit.namePatternGroups`에 보존했다. 그룹은 중복될 수 있고 `골프존카운티` 같은 정규 골프장도 포함할 수 있으므로 이 수를 제외 후 정규 골프장 수로 계산하지 않는다.

## 3. 좌표·중복·이름의 처리 원칙

node 좌표는 원천 좌표를 그대로 사용한다. way와 relation은 Overpass `out center`가 제공한 경계 상자 중심을 대표점으로 쓴다. 중심은 실제 코스 내부, 입구, 주차장, 클럽하우스를 보증하지 않는다. 이 차이를 각 객체 `coordinateMethod`와 전체 제한사항에 보존했다. 도로 경로의 출발·도착점을 정밀하게 설정하는 용도로 사용할 경우 별도 입구 확인이 필요하다.

중복 제거 키는 `type/id`다. 이름이 같거나 가까이 있다는 이유로 객체를 병합하지 않았다. 같은 시설을 node와 way로 나눠 등록한 경우, 18홀 코스 여러 개를 별도 way로 등록한 경우, 같은 이름을 쓰는 다른 지역 시설을 자동 판별할 근거가 부족하다. `audit.sameExactNameGroups`는 검토 후보일 뿐 삭제 목록이 아니다. 원천의 `tags`를 모두 보존해 추후 이름·주소·공식 URL·경계 관계를 사람이 점검할 수 있다.

주소는 `addr:full`을 우선하고 없으면 원문 `addr:*` 구성 요소를 이어 붙였다. 시도나 상세주소가 없을 때 좌표를 역지오코딩한 값이나 추정 지역명으로 채우지 않았다. 웹사이트는 원문 `website` 또는 `contact:website`다. 원문에 기재되었다는 것은 공식 사이트 확인과 다르므로 앱의 링크 안전 검사와 공식 예약 근거를 별도로 유지해야 한다. 영업 상태 역시 `unverified`를 기본값으로 했다. `access=no`처럼 제한을 암시하는 태그와 폐업은 같은 개념이 아니므로 폐업 확정으로 바꾸지 않는다.

## 4. 기존 4개 공식 카탈로그 대조

검증 결과는 `output/osm-explicit-matches-v2.json`에 별도로 기록했다. 서울 해비치와 아난티 코드는 기존 카탈로그의 `coordinates.osm_url`이 전국 원천의 way642736074와 way524471443에 정확히 대응한다. 해당 두 코스의 공식 가격·주소 정보를 전국 객체에 연결할 근거가 있다.

아난티 제주는 원천에서 `세인트포 CC`, way369959208로 남아 있다. [한국지방세연구원 정책과제 2024-25](https://www.kilf.re.kr/cmm/fms/PDF.do?atchFileId=FILE_000000000011878&fileSn=0)의 PDF 64쪽(인쇄46쪽)에 아난티의 이전 명칭이 세인트포였다고 명시돼 있다. [공식 아난티 제주 위치 안내](https://ananti.kr/ko/jeju/journey/location)의 구좌읍 입지와 기존 제주관광공사 대표점도 일관된다. 이름 유사도로 자동 매칭한 것이 아니라, 구명칭 관계를 확인한 수동 대조다. 원천 이름과 중심좌표는 보존한다.

[아난티 공식 TIMES 414](https://ananti.kr/ko/board/times/414)의 2022년 기록도 세인트포 골프장을 아난티 제주로 리노베이션하는 관계를 확인한다. 이는 현 운영상태나 모든 코스 경계의 동일성을 별도로 검증했다는 뜻은 아니다.

해비치 제주는 매핑하지 않았다. 기존 VisitJeju 좌표(33.3589911,126.7244129) 가까이에 이름 없는 node2975717086과 부영CC way582796107이 있지만, 해비치라는 증거가 없다. [공식 해비치 주소](https://www.haevichi.com/ccjeju/ko/course-guide)는 남원읍 원님로399번길319다. 단지 가까운 원천에 해비치 이름을 붙이면 잘못된 코스·예약 연결이 생길 수 있다. 기존 좌표와 공식 주소의 일치 여부를 추가 확인 대상으로 전달했다.

의령친환경골프장은 way645101379의 정확한 이름과 원문 웹사이트가 일치한다. 별도 의령리온CC way669452632와 구분했다. 독립 조사 담당이 확보한 Commons 사진과의 명칭 대응을 전달했지만 사진 촬영지 좌표를 코스 대표점으로 쓰지 않았다. 원천 OSM에 이미지가 있다고 보고하지 않았으며, 사진 권리·크레딧·실제 렌더 확인은 별도 산출물과 구현 검증에 따른다.

## 5. 공적 명부 확인의 현재 경계

[LOCALDATA](https://www.localdata.go.kr/)와 공공데이터포털에서 골프장업 전국 CSV를 찾았으나 이 세션에서 인증 없는 공식 전국 CSV를 확보하지 못했다. 사이트 본문은 웹 도구에서 시간 초과가 발생했다. 로그인이나 서비스키를 만들거나 비공식 복제본을 공식 원천으로 둔갑시키지 않았다. 따라서 원천상 미등재 골프장, 공식 영업 중 시설의 OSM 누락, 폐업 시설 잔존, 공식 좌표 누락률은 아직 계산할 수 없다.

대체로 [문화체육관광부 전국 등록·신고 체육시설업 현황](https://www.mcst.go.kr/site/s_policy/dept/deptView.jsp?pSeq=2115&pDataCD=0417000000&pType=07)의 공식 페이지를 실시간 확보했다. 제목은 2025 전국 등록·신고 체육시설업 현황(2024년 말 기준), 게시일은 2026-03-11이다. PDF 8MB와 HWP 10MB 첨부가 있으나 현재 인덱스와 일대일 결합을 마친 명부가 아니다. 게시연도·통계 기준연도·현시점 영업상태를 섞으면 안 된다. 해당 문서의 통계와 OSM 개수를 단순 차감해 누락 수라고 제시하지 않는다.

공식 PDF 실다운로드는 8,676,356바이트, 1,401쪽이며 재수집 없이 로컬에서 읽었다. PDF36~37쪽(인쇄28~29쪽)의 전국 등록 골프장업 요약은 539업소, 회원제154·대중제375·비회원제10이다. 이는 2024년 말 등록 스냅샷이며 현재 영업 중인 유일 시설 수가 아니다. 시도별 상세표에서 같은 시설의 회원제·대중제 행을 따로 기록한 사례가 확인된다(태광·레이크사이드·아난티제주·해비치제주 등). 상세표 열은 업소명·소재지·면적·홀수·세부종류·보험·지도자 배치이며 위경도나 현재 영업·폐업 상태 열이 없다. 따라서 명부를 읽더라도 좌표 없는 행에 추정 좌표를 생성하거나 등록행 전체를 영업 중이라고 표기하지 않는다.

`scripts/extract-official-register.py`로 목차의 골프장업 등록표와 다음 절 시작 페이지에 걸친 표를 추출했다. 결과는 `output/official-register-audit-v2.json`이며 상세표 553행을 보존했다. 공식 전국 요약539와 14행 차이가 있고 원문·추출 정합성 원인은 해결되지 않았다. 따라서 완성된 전국 명부로 취급하지 않는다. 각 행은 원문 명칭·주소·종류·홀수·PDF페이지를 보존한다. 공백 제거와 영문 대소문자 통일만 한 정확한 이름 비교에서 OSM 이름 후보가 있는 행은134, 없는 행은419다. 별도 주소·시설 동일성 검증이 없으므로134는 실제 매칭 수가 아니며419는 실제 OSM 미등재 수가 아니다. 자동결합은 수행하지 않았다. 좌표열 보유0, 현재 영업상태 검증0이며 등록행 전체를 운영 중으로 간주할 근거가 없다. 이 자료는 공식 원천을 확보한 부분 대조 감사로 남기고 전국 완전성 판정은 보류한다.

향후 대조에서는 공식 관리번호, 사업장명, 주소, 인허가일, 상세 영업상태, 폐업일, 기준일, 좌표계와 좌표 원문을 확보해야 한다. 같은 이름만으로 자동 결합하지 않고 주소와 공식 홈페이지까지 대조한 확정 매핑을 별도로 남긴다. 좌표가 없는 공식 행은 코스 수에는 포함하되 지도의 위치를 추정 생성하지 않는다. 운영 중 행만 따로 집계하며 군 체력단련장·공공시설·연습장 등 포함 범위를 명시해야 한다.

## 6. 공개 서비스와 갱신

[Overpass 공식 운영 문서](https://wiki.openstreetmap.org/wiki/Overpass_API)는 공용 인스턴스의 자원 제한과 캐시 사용을 안내한다. 본 작업은 단일 전국 요청으로 스냅샷을 만들고 지도 이동마다 재요청하지 않는다. 스크립트는 자동 재시도·병렬 전국 조회를 하지 않으며 오류 응답, partial remark, 지나치게 작은 응답이 나오면 기존 JSON을 보존한다. 새 응답을 정규화한 뒤 임시 파일에서 교체한다.

수동 갱신은 `node scripts/update-courses.mjs`, 이미 받은 원문 재처리는 `node scripts/update-courses.mjs --input .tmp/data/overpass-golf-kr.json`이다. 공개 앱의 사용자 수가 늘면 공용 Overpass에 전체 트래픽이 전가되지 않도록 현재의 정적 JSON 배포를 유지하거나 자체 데이터 공급원을 마련한다. 데이터 재사용에는 ODbL과 OpenStreetMap 기여자 표기가 필요하다. OSM 데이터 라이선스가 외부 사진의 저작권까지 허용하지는 않는다.

## 판정과 남은 일

확인된 사실: 전국 범위 질의·1,119개 객체 보존·좌표 검증·중복 키 검사·원천 시각 및 라이선스 기록은 완료했다. 해석: 초기 4개 한정 지도보다 전국 탐색 범위가 크게 넓어졌으나 영업·정규 코스 여부·명부 대비 완전성을 판단할 근거는 부족하다. 추가 확인: 공식 CSV 확보 및 관리번호 대조, 명칭 변경과 동일 시설 복수 객체 수동 검증, 해비치 제주 위치 보강, 시도별 완전성 산정이 필요하다.

이 문서는 데이터 수집 담당의 사실 기록이며 독립 검토나 전국 완전성 판정을 대신하지 않는다.
