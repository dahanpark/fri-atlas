# v2 지적사항 VF1·VF2 후속 수정 확인

확인일: 2026-10-22. 사용자 계속 진행 요청에 따른 두 지적의 수정 여부만 확인했다. 새 전체 검토·재채점·3차 합격 판정이 아니다. `output/review-final-v2.md`의 불합격·평균9.2점은 당시 동결본에 대한 기록으로 그대로 유지한다. 확인자는 제작 소스나 테스트를 수정하지 않았으며 이 문서만 추가했다.

## VF1 브랜드명에 따른 스크린 오분류

수정 확인: `dist/data.js`의 스크린 판정에서 브랜드 단독 문자열 ‘골프존’이 제거됐다. 전국 원천의 골프존카운티14개 객체 전부가 스크린이 아니며 categoryPenalty=0이다. 공식 근거가 있는 선산 `osm:way/386241143` 1개만 VERIFIED_TYPES로 ‘코스’에 연결하고, 나머지13개는 ‘유형 미검증’으로 남긴다. 근거없이14개 전부를 정규 코스로 확정하지 않는다.

새 회귀검사는14개 전수 분류·패널티, 선산 카드의 스크린 표시 제거, 선산이 브랜드 오분류 때문에 일반 비교코스 뒤로 밀리지 않음, 실제 ‘스크린’ 명시 이름의 분류 유지를 검사한다. 기존 검토 당시 직접 확인한 선산 공식18홀 근거와 연결이 일치한다.

## VF2 경로 실제 조회시각 누락

수정 확인: `dist/routing.js`는 실제 응답시각 checkedAt과 목적지 좌표·대표점 방법·스냅거리·경고를 보존한다. `dist/views.js routeEvidenceRows`가 서울시청/부산시청 각각의 실제 조회시각·제공처·목적지 대표점·스냅거리·경고·실시간교통 미반영을 근거 펼침에 출력한다. `exportReport`의 현재목록과 별도4비교 ID합집합 상세도 같은 evidence를 사용한다.

새 회귀검사는 서로 다른 과거 서울/부산 조회시각과 제공처, 목적지 좌표, 1501m 스냅경고가 화면 근거와 지역간 별도비교 HTML에 남는지 확인한다. 새로운 분석시각으로 원래 route 객체를 변경하지 않는 것도 검사한다.

추가로 확인자가 일회성 mock 실행을 직접 수행했다. 같은 목적지로 두 번 fetchRoads를 호출했을 때 fetch1회만 발생하고 반환 경로의 원래 조회시각·목적지·스냅경고가 동일하게 유지됐다. 이는 캐시 데이터 구조 확인이며 외부 경로 API 실호출 검증을 대신하지 않는다.

## 직접 실행 증거와 한계

- `node --test tests/core.test.js tests/v2.test.js`: 28/28 통과, exit0. 확인자가 직접 실행했다.
- 수정파일 `dist/data.js`, `dist/routing.js`, `dist/views.js`의 `node --check`: 모두 exit0.
- 지적된 VF1·VF2의 소스 및 회귀 경로에서 수정이 반영된 것을 확인했다. 이번 범위 밖 기능·접근성·모바일·외부 API·공개URL·공개asset SHA를 새로 검증하거나 전체 무결함을 선언하지 않는다.

전국 운영 골프장 완전성은 계속 미확인이다. 1119 OSM객체와 공식 미매칭1개로 구성된1120표본은 운영시설 총수가 아니다. NAVER 실제 별점·후기수는 미연결, 권리확인 실사는 의령1곳, 공식 가격자료는4코스 범위, 예약플랫폼은 일반서비스 링크이며 코스별 예약·결제API가 아니다. 원문 전체 요구의 자료확보는 여전히 부분완료다.

기존 전체 검토 기록은 보존하며, 이번 기록은 그 뒤 이루어진 두 지적의 수정 확인이다. v2 공개배포 성공과 공개화면·asset 일치 확인은 별도 단계다.
