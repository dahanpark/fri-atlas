# FRI ATLAS v2 외부 연동 조사
확인일 2026-10-22. 조사 범위는 공개 문서·공개웹이며 API 키, 제휴 계약, 로그인 리뷰 수집은 수행하지 않았다.

## 판단
네이버 별점은 2026년에 재개됐으나 공식 지역검색 API가 별점·방문자후기를 제공하지 않는다. 예약·길찾기 외부 페이지 연결은 지금 구성할 수 있지만, 카드 속 리뷰·실시간 도로거리 자동 갱신은 별도 인증·계약·허용범위가 필요하다. 검색 링크를 데이터 연동 완료로 표시하면 안 된다.

## 네이버 현재 사실
- 2021년 별점 종료 공지는 현재의 최종 상태가 아니다. 2026-04-06 방문 내역부터 별점 수집을 재개했고 07-09부터 평균·개별 별점을 공개한다. 과거 별점과 신규 별점을 합산하며 업체는 평균 노출 ON/OFF를 정한다. 업종별 재수집 대상 차이가 있으므로 모든 골프장에 평균별점이 있다고 단정하지 않는다. [공식 2026 공지](https://new.smartplace.naver.com/notices/1028), [공식 도움말](https://help.naver.com/service/30026/contents/20497?lang=ko).
- 공식 지역 검색 API의 반환값은 이름·링크·분류·설명·주소·좌표 등이며 NAVER 방문자 별점, 방문리뷰 수, 리뷰 원문을 반환하지 않는다. `sort=comment`는 카페·블로그 리뷰 개수 기준 정렬로 방문자리뷰 수 필드가 아니다. client ID/secret을 발급해야 한다. [지역검색 명세](https://developers.naver.com/docs/serviceapi/search/local/local.md).
- 이번 공개웹 조사에서는 m.place.naver.com 골프장 검색 페이지를 읽지 못했고, 골프장별 네이버 별점/방문후기수/원문 4곳을 확인하지 못했다. 값은 null로 유지한다. 공개 API가 없다는 조사 결과가 네이버와의 비공개 제휴 가능성 부정을 뜻하지 않는다.
- 정책은 서비스 안정성 저해·무단 추출 프로그램을 문제 행위로 다룬다. 공개 화면이 보이는 사실만으로 자동 대량 수집·GitHub 재배포권이 생기지 않는다. 차단·로그인·캡차 우회, 비공개 내부 endpoint 재현을 하지 않는다. [이용약관](https://policy.naver.com/rules/service.html), [공식 정책 안내](https://searchadvisor.naver.com/guide/content-abusing).
- 구현 라벨: 별점 칸은 “—”, 근거 패널 한곳에 “NAVER 미연결”, CTA는 “네이버에서 보기”. 이름+지역 검색은 검색 링크이며 특정 place ID가 검증된 장소링크와 구분한다.

## 서울·부산 자동차 거리·시간
기준은 서울시청/부산시청을 명시하고 출발지 좌표·목적지 입구·조회시각·차종·탐색옵션을 고정한다. 시청에서 대표점까지의 직선거리는 도로거리로 표시하지 않는다.
- 카카오 공식 URL은 키 없이 외부 웹 길찾기를 열 수 있다: `https://map.kakao.com/link/by/car/{출발명},{위도},{경도}/{목적명},{위도},{경도}`. 세그먼트별 이름 인코딩 필요. [공식 URL 가이드](https://apis.map.kakao.com/web/guide/).
- 이 링크는 앱 안으로 거리/시간을 반환하는 API가 아니다. 카드 숫자는 실제 경로 응답 없으면 null, 버튼은 “서울시청 출발 길찾기” 등으로 표시한다.
- NAVER Directions5는 실제 교통정보 기반 경로·거리(m)·시간(ms)를 반환한다. 출발/도착 좌표는 경도,위도 순이다. 계정·애플리케이션 인증이 필요하다. [공식 API](https://api.ncloud-docs.com/docs/en/ai-naver-mapsdirections-driving). 무료할당량이 있는 상품도 무인증 무료서비스는 아니다. 과금은 계정/신규Maps 정책별 최신 콘솔 확인을 권고하며 이번에 결제 활성화하지 않았다.
- 카카오모빌리티도 현재/미래 길찾기·다중목적지 등을 제공하나 개발앱 키와 사용조건/쿼터 확인이 필요하다. [공식 시작하기](https://developers.kakaomobility.com/guide/navi-api/start.html).
- 서울/부산→제주는 육지 도로만으로 연결되지 않으므로 항공·선박을 자동 가정해 운전시간을 만들지 않는다. API 결과가 없는 경우 경로미조회로 두고 외부 경로 확인을 제공한다.

## 완료 범위
공식 정책/링크 규격과 확인된 가격·후기·사진 권리 샘플을 문서/JSON으로 제공했다. NAVER별점 자동수집, 전국후기요약, 실제도로거리 API, 예약API, 기존4코스 실사썸네일은 미완료다. 키/계약/허가 없이 이미 연동됐다고 보고하지 않는다.

## 긴급 위치 재검증
2026-10-22 공식 지도 원문을 추가 확인했다. 해비치 제주 [공식 찾아오는길](https://www.haevichi.com/ccjeju/ko/location)이 로드하는 공개 지도 스크립트 `/ko/pc/js/cc_sub/map_jeju.js?v=2`는 `/getMap.do`에 `mapUrl=ccjeju&lang=ko`로 요청한다. 실제 공개 응답은 위도33.358839·경도126.728099, 주소 제주특별자치도 서귀포시 남원읍 원님로399번길319를 함께 제공했다. 공식 지도 클릭 링크는 https://naver.me/xwmhNyxR 이다. 서울도 같은 방식의 `mapUrl=ccseoul` 응답에서 위도37.613440·경도127.289620 및 재재기로190번길160을 확인했다.

기존 제주 관광공사 값33.3589911·126.7244129는 이름·주소가 같은 페이지에서 가져온 값이지만 실제 골프장 영역/입구와 공간적으로 교차 검증하지 못했다. 따라서 위치 동질성 검증 완료로 보고했던 판단은 불충분했다. 새 공식 지도점과도 차이가 있어 이전 값을 그대로 유지하지 않는다. 서울의 OSM 대표점127.2977과 공식지도점127.289620도 다르다. 코스 중심과 입구를 혼용하지 않는다. 공식 사이트가 표시하는 점이라는 사실까지만 확인했으며, 실제 차량 입구와 OSM 코스 영역 충돌 여부는 별도 검증 대상이다. `enrichment-v2.json.position_audits`에 출처·수정 이전값·정확한 검증 상태를 기록했다.

아난티 코드 원출처는 Ananti Chord Golf Club 명칭·golf_course·ananti.kr 링크까지 확인된 OSM 파생 대표점이며 출입구 검증은 아니다. 아난티 제주 관광공사 페이지는 현재 제목AnantiJeju·선유로445-55·본문SaintFourGolfCourse를 함께 제공한다. [아난티 공식 2022 기록](https://ananti.kr/ko/board/times/414)은 세인트포 골프장을 아난티 제주클럽으로 리노베이션하는 계획을 명시한다. 같은 부지의 명칭 연혁을 지지하지만 해당 관광공사 좌표가 정확한 입구라는 증거는 아니다.
