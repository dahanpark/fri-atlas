# v3 독립 자료 검토

검토일: 2026-10-22. 제작·자료 수정에 참여하지 않은 검토. 범위: `v3-course-stories.json`, `v3-stories-research.md`, `v3-fees.json`, 최종 dist 통합은 동결 후 추가 확인.

## 원문 자료 검증

- 후기 6건의 공개 본문을 각각 직접 열었다. 곤지암 2020·2022년 올댓골프리뷰, 그린힐 2026년 티스토리·2024년 그린라이트, 360도 2026·2025년 티스토리다. 날짜·그린 관리/동선/공사/조명/바람/그린 거리감 요약은 본문과 일치한다. 곤지암 두 글은 같은 리뷰어로 보이는 재방문 기록으로 표기하여 독립 2인의 의견으로 과장하지 않는다. 그린힐 장점이 주로 한 글에서 나온다는 조건도 보존했다. 소표본·방문시점 환경·최신상태 미보장 조건이 있다. 네이버 직접본문 차단 후 대체 공개 블로그를 사용했다는 기록과 네이버 제외출처가 일치한다. 원문 문장 장문복제나 원문사진 복제는 없고 요약은 짧다.
- 공식 소개: 신안그룹 그린힐 소개(숲·넓은 페어웨이·언듈레이션·18홀·동곤지암IC·시설), 360도 소개/코스/잔디 페이지(여주·파72·18홀·인아웃·잔디구분), 곤지암 공식 이용가이드(3~4인팀·예약·복장) 직접 열람. JSON 3문장과 모순되는 항목을 발견하지 않았다. 곤지암 산세·호수/두코스 명칭은 관광정보 전재 프로필에도 있다. 홍보성 공식 소개와 이용자 후기를 구분한다.
- 곤지암 공식 영문 요금표: 비회원 평일 280,000원·주말 300,000원, 일반 캐디 150,000원·기능 캐디 170,000원, 카트 120,000원 직접 확인. 4백1캐디·1팀1카트 운영 근거 있음. 공휴일 및 시행일 미확인 조건 적절.
- 가평베네스트 공식 이용요금: 비회원 평일 250,000원·휴일 310,000원, 일반 캐디 160,000원·카트 100,000원, 리무진 캐디/카트 및 휴일 범위 직접 확인. 캐디·카트 팀/인당 문구는 해당 표에 명시되지 않아 단위 미확인으로 보존한 점 적절.
- 가야 공식 iframe 요금표: 회원제 18홀 비회원 평일 210,000원·주말 250,000원, 카트 팀당 100,000원 VAT포함, 캐디 150,000원·외국어캐디 200,000원 직접 확인. 퍼블릭 9홀과 혼합하지 않는다. 캐디 과금 단위 미확인 보존 적절.
- 360도 공식 요금안내: 일반 캐디 150,000원/팀, 리무진 4인 170,000원/5인 230,000원, 5인승 카트 100,000원·리무진 220,000원, 공홈 외 예약 비회원가·사이버회원 내장전일 가입 조건 직접 확인. 10/19~25 그린피 원JPG는 web 도구에서 열리지 않아 검토자가 6시간대 금액을 독립 시각판독하지 못했다. 그린피 17~20/23~27만원은 제작자의 원이미지 시각판독에 의존하는 검증 경계다. 날짜·비회원 가산 계산 근거가 JSON에 명시되어 있다.
- 그린힐·감곡의 공식 차단 때문에 금액을 채택하지 않은 처리와 미확인 이유는 일치한다. 제3자 옛 요금을 공식 현재가로 대체하지 않는다.

## 사진 동일성·사용조건

- 관광정보 전재 프로필의 사진 링크를 직접 클릭하여 곤지암 1956867, 그린힐 1956874, 360도 2781828 원URL과 JSON의 정확한 연결을 확인했다. 이름·주소가 조사 코스와 일치한다. 원이미지 web 로딩은 세 장 모두 cache miss였고 관광공사 개별 프로필은 timeout이었다. 실제 장면·로딩 판정은 루트의 브라우저 검증이 필요하다.
- [관광공사 공식 데이터 설명](https://www.data.go.kr/data/15101578/openapi.do?recommendDataYn=Y)에서 API가 자유활용 가능한 자료를 선별하고, 사진은 공공누리 1·3유형을 제공하며 CI/BI·인격권 침해 용도를 금지한다는 문구를 직접 확인했다. 이는 서비스 전체 범위의 설명이며 특정 사진이 1유형이라는 개별 증명은 아니다. JSON이 개별 유형 미확인으로 남긴 점 적절하다. 출처·이용조건 링크·무변형 contain 표시를 필수로 적용하고 HTML에서는 제외하는 보수적 처리가 필요하다.
- 타코스·AI·공통로고를 대표 전경으로 사용하지 않은 조사 기록은 적절하다. 전국 모든 골프장의 대표사진을 확보한 결과로 보고해서는 안 된다.

## 동결 후 최종 확인 항목

1. 위 원본 자료와 최종 dist의 ID·요금·조건 일치.
2. 360도 한정기간과 회원구분이 카드/비교표/HTML에 가려지지 않고 노출되며 다른 선택날짜 견적으로 오해되지 않음.
3. 사진 원구도 contain, 크레딧·원출처·이용조건 링크와 사진별 exportAllowed 분리.
4. 공식 3문장과 후기 소표본/방문시점/독립작성자 한계가 화면 조건정보에 유지됨.

## 최종 dist 통합 대조

현재 `dist/v3-fees.json`은 조사 원본과 SHA256이 같다. `dist/v3-course-stories.json`은 원URL·코스 ID·후기 2표본씩·3문장·한계조건을 보존하고 화면허용 `tourapi_reference`와 반출불허를 구분한다. `applyV3`는 정확 ID로만 연결한다.

독립 Node 모듈 호출로 실제 `applyV3`→`card`·`exportReport`를 검사했다. 3코스 모두 `photoFor=true`, 공식3문장, 후기 한계조건 및 모든 원문 링크가 카드에 남는다. 360도 카드에 2026-10-19~2026-10-25 한정 문구가 직접 표시된다. 생성 HTML에서 KTO 사진 URL과 반출불가 장단점 요약은 제외되고, 공식3문장·기간·후기 출처/한계는 보존된다. `estimateCost`는 선택일 확정견적이 없으면 총액을 계산하지 않는다. CSS 최종규칙은 카드/비교썸네일 모두 `object-fit:contain`이며 크레딧 함수가 원출처·한국관광공사·이용조건 링크를 출력한다.

루트 브라우저 검증의 전달기록: KTO 3원URL을 각각 직접 열어 정상로드·골프시설 장면과 기존 출처 워터마크 보존을 확인했다. 곤지암·그린힐은 주로 클럽하우스/진입·주차 전경으로, 페어웨이 파노라마라는 표현 대신 대표이미지로 표시한다. 이는 검토자 자체 시각검증과 구별한 팀의 실행 증거다. 개별 공공누리 유형 직접확인으로 확대하지 않는다.

판정: 확인된 3코스 소개·후기·조건부 화면사진 및 4코스 공식요금의 자료·통합 범위에서 수정필수 결함을 발견하지 않았다. 360도 주간표의 6시간대 숫자는 검토자가 독립 시각판독하지 못한 범위로 남는다. 전국 사진·요금·후기 확보 완료를 뜻하지 않으며, 실화면 배치·모바일·비교 추가·공개 배포는 기능/브라우저 검토 범위다.

최종 동결 통보 후 재대조: 비교표 헤더의 긴 사진 크레딧은 별도 `사진 출처·이용조건` 접기로 이동했으며 출처/이용조건 링크가 보존된다. 후기 짧은 셀에 연도범위·2편·일부표본을 추가하여 방문시점 오해를 줄였다. 상세 `greenFeeText`도 최저~최고와 기간을 함께 보존한다. 동결본 모듈 검증의 범위·기간·후기라벨·크레딧·HTML권리별제외 assert를 모두 통과했다. 수정필수 결함 없음으로 이 검토서를 확정한다.
