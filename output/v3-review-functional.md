## 코드 확인

- `.results-column` 전체 스크롤을 해제하고 `.shortlist-panel`만 높이 제한·독립 스크롤한다. `#planningPanel`은 같은 오른쪽 열에서 바로 뒤 형제 요소다. 비교 추가·제거는 Map snapshot을 즉시 갱신하고 `rerender`에서 표를 갱신한다. 첫 추가 시 패널로 스크롤하고 키보드 입력에는 포커스를 준다. 비교 헤더의 긴 크레딧은 표 아래 펼치기로 옮겨 표 높이를 줄였다.
- NAVER 미연결 문구·평점행·검색링크는 현행 카드·비교·HTML 내보내기 경로에서 제거됐다. 정렬은 확보된 공식요금·소개·후기 정보 우선이며 품질순위로 설명하지 않는다. 남은 NAVER 유틸리티와 옛 reportHTML은 현행 UI 호출 경로가 아니다.
- 새 요금 결합은 ID 완전일치로만 한다. 범위 상한·회원구분·기간을 보존한다. 미확인 캐디 단위는 팀당으로 추정하지 않는다. 총액은 선택일·인원·모든 필수비가 확인된 quote가 없으면 산출하지 않으므로 한정기간 밖 360도CC 일반표가 확정총액으로 전환되지 않는다.
- 공식 특장점은 확인된 3문장만 표시하고 HTML escape한다. 이용후기와 구분한다. 새 후기셀에는 연도 범위·2편·일부표본을 짧게 직접 노출하며 펼치기에는 제공처·종류·표본·대표성·확인일과 한계를 유지한다.
- 사진은 해당 코스 ID/명칭 매칭·안전 URL·권리 필드를 통과해야 한다. 새 TourAPI 3장은 화면 원격참조, 원구도 contain이며 HTML에서는 사진 URL을 빼고 출처 링크만 남긴다. 기존 CC 사진만 HTML 이미지가 허용된다. 일반 타코스·합성 사진으로 결측을 채우는 경로는 없다. 실패 이미지에는 아이콘 복구가 있다.
- HTML은 현재 TOP와 지역이 다른 선택 코스의 ID 합집합에 상세 근거를 한 번씩 남긴다. 반출불허 후기 요약은 제거하고 출처·표본 한계만 보존한다. 경로 실제 조회시각·제공처·목적지·스냅 경고를 유지한다.
- 기존 전체 viewport 마커/TOP10·20 분리, 저장 snapshot, 최대4곳, 비동기 취소·요청ID 방어, 안전 URL·문자열 escape 회귀가 통과했다.

## 실제 화면 확인 경계

루트의 실브라우저 확인 전달: 데스크톱에서 세 대표사진 naturalWidth 699/699/940 로드와 contain, 첫 비교 추가 직후 지도와 비교 패널이 한 화면에 표시되는 동작을 확인했다. 이 검토자가 브라우저를 별도로 조작한 결과는 아니다. 내보내기 실제 저장 동작은 루트 검증 기록을 함께 확인해야 한다.

검토자가 직접 연 `output/v3-comparison-preview.jpg`에서 세 코스의 서로 다른 사진과 바로 위 목록/왼쪽 지도를 확인했다. `output/v3-mobile-preview.jpg`의 최초 파일은 데스크톱 화면이어서 모바일 증거로 쓰지 못함을 지적했고 루트가 교체했다. 교체본도 직접 열어 좁은 iframe의 비교표 내부 가로 스크롤과 하단 레이아웃을 확인했다. 루트 측정: 390px iframe에서 스크롤바 제외 문서 clientWidth/scrollWidth 각375, 비교 wrapper client329/scroll446. 문서 가로넘침 없이 표 내부만 가로스크롤하는 동작을 확인했다. 실제 모바일 기기·터치 검증이 아닌 브라우저 iframe CSS 검증이다.

추가 보강 재검토: 루트 실QA에서 발견한 그린힐 기본정보 누락은 최종 `basic_info` 독립 결합으로 수정됐다. 새 회귀를 직접 실행해 내선길 176·18홀·공식 홈페이지 표시와 그린피/캐디 결측 유지, 곤지암18홀·가평27홀 헤더를 확인했다. 가격을 얻지 못한 코스도 공식 기본정보를 표시하며 허위 요금을 생성하지 않는다. 최종 결합 모듈 구문 검사도 exit 0이다.
