# v4 독립 전체 검토

검토일 2026-10-23. 제작 코드 수정에 참여하지 않은 독립 검토다. 최신 사용자 요청과 프로젝트 스킬, dist의 app/data/views/core/enrichment-v3/index/styles, v3 공개자료 JSON, 기존 v3 자료·기능 검토서를 읽고 직접 회귀를 실행했다. 추가 조사 자료의 최종 병합은 후속 대조 대상으로 남긴다.

## 직접 확인

- `node --test tests/core.test.js tests/v2.test.js`: 36/36 통과, 실패 0. 지도 이름표 임계값, 추천 배치 근거, 관광공사 참고요금 분리까지 포함한다.
- 지도 `renderMap`은 TOP10/20과 별개인 viewport 전체 후보를 기준으로 마커를 만든다. 현재 보이는 수가 1~49일 때만 Leaflet tooltip을 permanent로 설정한다. 이름은 DOM textContent로 전달하므로 원천 문자열이 HTML로 해석되지 않는다.
- 비교 영역은 결과 목록 바깥의 다음 형제 `#planningPanel`이다. 목록은 독립된 높이·스크롤을 가지고, 비어 있을 때도 비교 슬롯이 표시된다. 표는 최대4곳, 내부 세로/가로 스크롤, 고정 헤더를 유지한다. 이는 지정된 오른쪽 영역에 항상 존재하는 레이아웃이며 화면 전체에 덮는 position:fixed 방식은 아니다.
- 검토자가 `output/v4-local-comparison.jpg`를 직접 열었다. 지도 이름표, 지도 오른쪽 별도 비교 영역, 곤지암의 실제 대표사진 및 요금, 연도·표본이 붙은 짧은 후기 항목을 확인했다. 루트가 전달한 브라우저 실행 기록은 화면 후보25개/이름표25개, KTO 사진 원본 폭699/699/940 로드다. 검토자가 브라우저를 독립 조작한 결과와는 구분한다.

## 정렬·자료 경계

- 기본 정렬은 공식18홀 요금·소개·검증된 후기 표본의 자료 확보순이다. 카드에 배치 근거와 품질 평점이 아님을 표시하며, 공개 평점을 합성하지 않는다. 가격 정렬은 확인된 18홀/인당 금액만 사용하고 결측을 뒤로 보낸다. 기존 NAVER 값은 추천 정렬에 사용되지 않는다.
- 따라서 이것은 전국 코스 품질 랭킹이나 네이버 별점순 구현 완료가 아니다. 현재 제한된 코스의 자료 확보량으로 앞에 배치된 이유를 설명할 수 있는 기능이다. 화면/최종 보고에서도 이 경계를 유지해야 한다.
- 그린힐 관광공사195,000/270,000원은 `referenceFees`에만 들어간다. 확정18홀·인당 공식요금 배열에는 들어가지 않으며 `feeValue`가 null을 유지한다. 카드·표·HTML 모두 관광공사 참고가 및 기준일·홀/단위 미확인을 표시한다. 캐디150,000원 역시 단위미확인이다. 정렬과 선택일 총액으로 승격되지 않는다.
- 선택일 총액은 별도 quote의 날짜·인원·모든 필수비 확인 없이는 계산하지 않는다. 360도의10/19~25 한정 요금은 기간과 비회원 조건을 함께 노출한다. 현행 표시값이 모든 날짜의 확정견적임을 뜻하지 않는다.

## 결합·사진·HTML

- 새 자료는 정확한 OSM source ID로 결합한다. 이름 유사도나 좌표 인접으로 다른 골프장의 요금·후기·사진을 붙이는 경로를 발견하지 않았다.
- 대표사진은 코스 ID/명칭 일치·안전 URL·권리 필드를 통과해야 한다. 세 TourAPI 사진은 원구도 contain의 원격 화면참조이며 HTML에서는 사진 URL을 제외하고 출처 링크를 남긴다. 기존 허용된 CC 사진만 내보내기 이미지가 된다. 일부 사진 확보를 전국 대표사진 완료로 보고해서는 안 된다.
- 후기 셀은 최대2개 장점·유의점을 짧게 표시하고 연도·표본수·일부표본 라벨을 보존한다. 상세 출처에는 제공처와 독립성/대표성 한계가 있다. 반출불허 후기는 HTML에서 요약을 제거하고 출처·한계만 남긴다.
- 외부 문자열 escape 및 안전 URL 처리가 적용돼 있고, 지역이 다른 비교 선택과 현재 TOP 목록의 합집합 상세는 ID 기준 한 번씩 생성한다. 잘못된 sourceUrl/사진 매칭과 executable scheme 회귀가 통과했다.

## 추가 공개자료 동결 검토

`output/v4-public-enrichment.json` 및 조사서를 읽고 실제 채택3코스와 dist를 대조했다. 가평베네스트·가야는 원래 OSM ID를 보존하고 아난티 코드는 기존 explicit-matches의 공식카탈로그-OSM 완전일치인524471443으로 코스와 photo.courseId를 함께 옮겼다. 매칭하지 못한 아난티 중앙은 dist에 채택하지 않았다. 사진 종류는 official_course_image로 화면 원격참조를 허용하되 자유재배포허락으로 주장하지 않으며 HTML에서는 제외한다. 사진·후기 반출필터는 유지된다.

검토자가 직접 공개 원문을 열었다. [가평 공식 코스](https://www.benestgolf.com/reve/pc/gp-course/main.do)의27홀·세코스·설계·지형 설명, [공식 앨범](https://www.benestgolf.com/reve/pc/gp-club-intro/album.do)의MAPLE6 이미지 연결, [아난티 코드 공식 코스](https://ananti.kr/ko/chord/CD0205)의27홀·세나무코스·고저차와 채택CDN 주소가 일치한다. [가평2025 방문기](https://happy-ja.tistory.com/53)와 [가야2025 방문기](https://www.dealbada.com/bbs/board.php?bo_table=forum_golf&wr_id=1264556) 본문을 각각 직접 읽었다. 짧은 관리·편의·난도/벙커·캐디 경험 요약은 본문과 일치한다. 가야의 캐디 불만과 반대 댓글의 경험이 상충함을 조건에 남겼고, 전체 서비스로 일반화하지 않는다. 가평의 다른 서비스 별점 재인용 및 검색된 AI점수·불일치 평점은 채택하지 않았다. 두 코스 각1편, 과거 시점, 대표성 없음, 반출불허가 보존된다. 새 사진의 직접 시각확인은 조사자/루트의 실행 증거이며 검토자는 모든 새사진을 독립 이미지판독한 것은 아니다.
